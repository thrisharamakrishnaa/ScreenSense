# 📊 Screen Time Analysis – Indian Kids Dataset

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the **Indian Kids Screen Time Dataset** to understand screen usage patterns, health risks, and behavioral trends among children and teenagers.

The goal is to analyze:
- Average daily screen time
- Recommended limit violations
- Health issue correlations
- Age-wise screen exposure
- Device usage patterns
- Educational vs recreational usage balance

---

## 🎯 Objectives

- Analyze average daily screen time across different demographics
- Identify proportion of children exceeding recommended limits
- Study correlation between screen time and health issues
- Examine trends across age bands (8–18 years)
- Understand device preference impact
- Generate insights for awareness and intervention strategies

---

## 🗂 Dataset Information

**Dataset Name:** Indian_Kids_Screen_Time.csv  
**Processed File:** screentime_cleaned.csv  

Key features include:
- Age
- Gender
- Urban/Rural
- Primary Device
- Average Daily Screen Time (hours)
- Educational to Recreational Usage Ratio
- Health Issue Indicator
- Exceeded Recommended Limit Flag

## 🔎 Exploratory Data Analysis Performed

### 1️⃣ Data Cleaning & Preprocessing
- Checked missing values
- Removed inconsistencies
- Created Age Bands
- Generated derived flags (e.g., exceeded recommended limit)
- Exported cleaned dataset

### 2️⃣ Univariate Analysis
- Age band distribution
- Gender distribution
- Device usage breakdown
- Health issue proportions

### 3️⃣ Bivariate Analysis
- Screen time vs health issue
- Screen time vs gender
- Screen time vs device type
- Screen time vs urban/rural
- Age band vs limit exceedance

### 4️⃣ Correlation Analysis
- Correlation matrix for numerical variables
- Analysis of relationship between:
  - Screen time
  - Educational/Recreational ratio
  - Health issue indicator

---

## 📈 Key Insights

- Majority of children exceed recommended screen time limits.
- Strong association between exceeding limits and reported health issues.
- Older age groups show significantly higher limit violations.
- Minimal correlation between educational ratio and total screen time.
- Device type slightly influences average screen exposure.
